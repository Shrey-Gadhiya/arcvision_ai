# ARC VISION — Behavioral Analytics & Temporal Threat Engine

## 1. Supported Behavioral Rules & Trigger Conditions

| Behavior Type | Evaluation Basis | Trigger Criteria | Security Implication |
| :--- | :--- | :--- | :--- |
| **Loitering** | Spatial Dwell Time | Track resides within restricted polygon $> t_{\text{loiter}}$ (e.g. 15s) | Reconnaissance, unauthorized presence |
| **Perimeter Pacing** | Heading Vector Flips | $> 3$ heading reversals ($180^\circ$) within 20m perimeter corridor | Sentry monitoring, breach point scouting |
| **Wrong-Way Movement** | Vector Angle Check | Track velocity vector opposite to configured lane vector ($> 120^\circ$) | Checkpoint bypass, contraband transport |
| **Unusual Stopping** | Velocity & Duration | Vehicle stops in sterile road corridor for $> 10\text{s}$ | Ambush, drop-off, vehicle breakdown |
| **Crowd Clustering** | Spatial Proximity | $> N$ persons converge within $5\text{m}$ radius for $> 10\text{s}$ | Unlawful assembly, perimeter storming |
| **Abandoned Object** | Track Disassociation | Stationary object remains after owner departs scene | IED / contraband drop |
| **Rapid Movement** | Kinematic Velocity | Person speed $> 4.5\text{ m/s}$ ($> 16\text{ km/h}$) | Fleeing, perimeter penetration sprint |
| **Night Restricted Movement**| Lighting & Schedule | Any target track active during restricted night hours (22:00–05:00) | Covert infiltration attempt |
